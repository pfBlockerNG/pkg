pfBlockerNG

Self-hosted FreeBSD pkg repository for pfSense CE & pfSense Plus.

Install pfBlockerNG straight from this repository: pick a channel below and run its commands on your firewall (as root).

Channels

Stable

Latest 3.3.0

Final tagged releases (X.Y.Z) from a maintained release line. Production use.

fetch -qo - https://pfblockerng.github.io/pkg/add-repo.sh \
  | sh -s -- --base-url https://pfblockerng.github.io/pkg --channel stable
pkg install pfSense-pkg-pfBlockerNG
Manual conf (advanced)

The bootstrap auto-detects this; in a hand-written conf, replace <varver> (the edition-version: ce-2.8, plus-26.03, …) with your box's value.

# Generated at boot by pfblockerng_repo_generate (ADR-39) — do not edit; re-run add-repo.sh to change.
# pfBlockerNG (stable channel) — self-hosted pkg repository (ADR-17).
# NONE-signed: trust anchor is HTTPS to the host (no signing key). The URL is
# fully resolved for this box's edition/version (ADR-39; arch-less/NO_ARCH,
# issue #1806); the boot rc.d hook updates it on a pfSense OS upgrade.
# priority 100 sits above the base Netgate `pfSense` repo so cross-repo
# resolution (pkg install/upgrade, GUI Install) selects the pfBlockerNG build.
pfblockerng-stable: {
  url: "https://pfblockerng.github.io/pkg/stable/<varver>",
  mirror_type: none,
  signature_type: none,
  priority: 100,
  enabled: yes
}
